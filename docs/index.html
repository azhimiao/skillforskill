What is Skill-Core?

Skill-Core is a vendor-neutral toolchain for building Agent Skills. You author skills in IR (references/ir.md), compile to runtime SKILL.md, test, and install to any compatible host.

Intent → IR → skill compile → SKILL.md → skill test → skill install

5-Minute Quickstart

python skill-core/skill.py init my-skill
# edit my-skill/references/ir.md + eval.yaml
python skill-core/skill.py compile my-skill
python skill-core/skill.py test my-skill
python skill-core/skill.py install my-skill --host cursor --scope global

Windows: skill init my-skill via skill.cmd

Registry

registry.json indexes skills in this repo. Build after adding skills:

skill registry build
skill list
skill list --tag example -v

Migrate Legacy Rules

Migrate Cursor rules, slash commands, or .cursorrules to Agent Skills format.

skill migrate .cursor/rules/my-rule.mdc --name my-rule
skill migrate-scan --project . --out ./skills

Migrated body content is preserved verbatim. Review generated IR and re-compile when ready.

Protocol

Skill-Core extends the Agent Skills open standard with:

  • 13-section IR for authoring discipline
  • Portable tool IDs (host-agnostic)
  • L0/L1/L2 evaluation tiers
  • Compile + drift detection

IR JSON Schema: skill-core/schema/ir.schema.json
